# 📋 Task Manager (Vazifalar Menejeri)

**Streamlit** asosida vazifalarni boshqarish ilovasi. Vazifa qo'shish, ustuvorlik belgilash va muddatni kuzatish.

---

## ✨ Imkoniyatlar

- ➕ **Vazifa qo'shish**
- 🎯 **Ustuvorlik:** past / o'rta / yuqori
- 📅 **Muddat** belgilash
- ✅ **Bajarilganini belgilash**
- 💾 **Sessiya** davomida saqlash

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **Streamlit** | Veb-interfeys |
| **pandas** | Ma'lumotlar |

---

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/TaskManager.git
cd TaskManager
python -m venv venv
source venv/bin/activate
pip install streamlit pandas
```

---

## ▶️ Ishga tushirish

```bash
streamlit run app.py
```
